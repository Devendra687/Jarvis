# 🤖 Jarvis AI

A voice-controlled AI assistant built with **Python** and **Google Gemini AI**.

Jarvis can recognize voice commands, speak responses, open websites, play music, and answer general questions using Google's Gemini API.

---

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech
- 🤖 Gemini AI Integration
- 🌐 Open Google
- ▶️ Open YouTube
- 📷 Open Instagram
- 👻 Open Snapchat
- 🎵 Play Songs from Music Library
- 🗣 Wake Word Detection ("Jarvis")

---

## 🛠 Tech Stack

- Python 3.11
- SpeechRecognition
- PyAudio
- pyttsx3
- Google Gemini API
- python-dotenv

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Devendra687/Jarvis.git
```

Move into the project

```bash
cd Jarvis
```

Create Virtual Environment

```bash
python -m venv .venv
```

Activate Virtual Environment

### Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
python -m pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the project folder.

```
GEMINI_API_KEY=YOUR_API_KEY
```

---

## ▶️ Run

```bash
python jarvis.py
```
